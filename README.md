## 🚀 How to Run Locally

You have three easy ways to view the website locally:

### Option 1: Direct Browser Opening (Quickest)
Simply double-click `index.html` or right-click `index.html` → **Open with** → **Google Chrome** (or Edge/Brave/Firefox).

### Option 2: Using Python (Recommended)
Open your terminal in the `portfolio` directory and run:
```bash
# In the portfolio directory:
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.

### Option 3: VS Code Live Server
If you use VS Code:
1. Install the **Live Server** extension.
2. Right-click `index.html` and click **"Open with Live Server"**.
