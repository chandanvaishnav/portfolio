Key Technical Highlights:
  • Pure JVM & Spring Boot 3.x backend with native Java ML (Smile / Oracle Tribuo) running in-memory

  • Non-Invasive Biometrics: Zero camera and zero microphone requirement (Target: sub-30ms inference latency)
